## Что работает на проде (para.skycoax.uz)

- Расписание всех 14 вузов, без интернета (service worker), режим преподавателя.
- Совместные пары: «Вместе с N группами» (`server/src/together.js`).
- Новая навигация: нижняя панель вкладок Расписание / Обсуждения / Профиль; вверху «Сегодня | Неделя»,
  «Правки» — круглой кнопкой справа (лист).
- Аккаунты: вход через Google (OAuth code + PKCE), гость по умолчанию, возраст ≥ 16 (`SOCIAL_MIN_AGE`).
- «Обсуждения» вуза: посты (до 4 фото), ветки ответов (1 фото), лайки, категории, жалобы, блокировки,
  модерация (модератор — kamolov1575@gmail.com), маскировка мата, лимиты, аварийный `SOCIAL_MODE`.
- Профиль: аватар, @имя, «о себе», Telegram/Instagram, друзья, поиск людей, удаление аккаунта.
- Страницы: `/policy`, `/rules`, `/delete-account` (разработчик «skycoax», данные в Узбекистане, Ташкент) — на всех адресах.
- Адреса вузов (kfu.skycoax.uz, tsue.skycoax.uz…) — та же Para с выбранным вузом: вкладки, вход, «Обсуждения»
  (вход через Google идёт через Para и возвращается на адрес вуза, см. раздел «Обсуждения» в `AGENTS.md`).
- «Обсуждения» и профиль — в стиле Threads: без тем сверху (новые посты уходят с темой «Разное» — `other`,
  сервер темы по-прежнему принимает), строки с разделителями, «Что нового?»; профиль — имя слева, фото справа,
  «Ветки»; настройки — экран за кнопкой ≡ (у гостя — прямо в «Профиле»).
- iPhone (iOS 26–27): ошибка WebKit сдвигает закреплённые элементы после клавиатуры — поправка `--vv-fix`
  в `web/src/ui/keyboard.ts`; проверить на iPhone после входа через Google и набора текста.
- Моменты (как Instants в Instagram, 26.09): карточка у правого края «Обсуждений», камера; видны сутки —
  по умолчанию всем вошедшим в «Обсуждениях» того же вуза (`audience 'all'`, схема V5), можно «Только друзья»,
  реакции и просмотры, архив «Твои моменты» (год) в настройках; фото моментов не публичные

  идут в общую очередь модератора (цель `i:<id>`). Схема social.db V5; копия до моментов —

## Ограничения облачной сессии

- SSH-ключа к VPS в облаке нет → выкладку (`DEPLOY_HOST=skycoax-vps bash deploy/deploy.sh`) и всё на сервере
  делает владелец со своего компьютера (или локальная сессия Claude).
- Play Console и Google Cloud — только через браузер владельца; пароли и коды вводит сам владелец.
- Проверка перед выкладкой: `cd web && npx tsc --noEmit && npm run build`,
  `for f in server/src/*.js server/src/social/*.js; do node --check "$f"; done`,
  дымовой тест соцчасти — раздел «Обсуждения» в `AGENTS.md`.
